# HaleHaven: AI Phishing URL Detection System

This project detects phishing URLs including AI-generated phishing URLs, human-crafted phishing URLs, tiny URLs, and zero-day attacks using ensemble machine learning.

## Features
- Detects AI-generated phishing URLs
- Supports tiny URL expansion
- Uses ensemble learning with second-layer SVM
- GUI-based phishing detection

## Technologies Used
- Python
- Machine Learning
- Tkinter
- Scikit-learn

## How to Run
1. Install Anaconda
2. Activate environment
3. Run `python gui.py`
